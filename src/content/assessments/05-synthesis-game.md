> Finish one game. Use only what it needs.

This is where the semester's constraint gets tested one last time, not by
adding to it but by editing it down: which primitives actually serve this
one game, and which would just be there because they exist.

## What you submit

The finished game and a short design note. The note matters as much as the
game: it should read like a decision record, not a feature list.
